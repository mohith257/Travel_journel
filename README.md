# Travel Journal App

A simple travel journal app built as a group assignment.

## Setup
```bash
git clone https://github.com/your-username/travel-journal.git
npm install
cp .env.example .env
npm run dev
```

## Branching
Always create your branch from `dev` — name it `feature/your-name`. Open a PR into `dev` when done, get one teammate to review before merging. Never push directly to `main`.
